# Vision integration

The public snapshot contains `inference/detect_snapshot.py`, a host-side adapter for an external YOLOv5 checkout. Source, weights, private datasets and generated runs are excluded.

See [setup](../docs/setup.md#real-yolov5-inference), [limitations](../docs/limitations.md) and [third-party notices](../THIRD_PARTY_NOTICES.md). Set `AI_LOCAL_WEIGHTS` explicitly for real inference; the software walkthrough does not require weights.
