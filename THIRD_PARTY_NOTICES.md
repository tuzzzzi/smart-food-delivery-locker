| Component | Role | Upstream |
| --- | --- | --- |
| Flask | HTTP server and template integration | https://github.com/pallets/flask |
| Flask-SQLAlchemy / SQLAlchemy | Database access | https://github.com/pallets-eco/flask-sqlalchemy ; https://github.com/sqlalchemy/sqlalchemy |
